# Smoking Health Risk Analysis

## Project Overview
This project presents an interactive Power BI dashboard focused on analyzing smoking habits and their potential relationship with health risk indicators.

The dashboard provides insights into smoking status, smoking duration, daily cigarette consumption, gender distribution, cholesterol levels, and hypertension risk across different age groups.

## Dashboard Features
- Smoking Status Analysis
- Smoking Distribution by Gender
- Smoking Duration and Daily Intake Analysis
- Cholesterol and Hypertension Risk Analysis
- Age Group Comparison
- Interactive Dashboard Elements

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Dashboard Preview
The dashboard provides a visual overview of smoking habits and related health indicators.
